wd# Hakuro 設計規範

適用版本：1.5.3。本文整理目前已實作的視覺與互動規則，供後續功能與修正沿用。修改設計時應同步更新本文；`concepts/` 是探索稿，實際介面以 `app/` 的程式碼為準。

## 1. 視覺方向

Hakuro 以可操作的立體方塊為核心，搭配深色海報式版面、粗體標題、細線框與單一強調色。完整模式提供歌曲資訊與歌詞閱讀空間；精簡模式保留方塊及必要控制，背景透明。

- 以黑、灰、白建立層次；強調色用於互動、進度、選取與光暈，不替不同功能任意新增色系。
- 標題與按鈕採緊湊、大寫的展示字體；數字、快捷鍵與狀態使用等寬字體。
- 保留方塊、唱片、音量環的實體操作感。新增控制優先放入既有面板、方塊工具列或 Command Palette。
- 裝飾不遮住文字、不攔截點擊；動畫的顯示與生命週期必須跟隨所屬內容。

## 2. 色彩與字體

共用 token 定義於 [base.css](../app/src/base.css)，所有視窗均應沿用。

| Token | 預設值 | 用途 |
| --- | --- | --- |
| `--accent` | `#e6ff1f` | 可自訂的強調色 |
| `--active-line` | `#f4f6f5` | 目前歌詞，可自訂 |
| `--past-line` | `#3e4040` | 已唱過歌詞，可自訂 |
| `--ink` | `#f1f1ec` | 主要文字 |
| `--ink-2` | `#a8a8a3` | 次要文字 |
| `--ink-3` | `#62625e` | 弱化資訊 |
| `--line` | `#272727` | 分隔線 |
| `--accent-glow` | 強調色 55%／透明 | 光暈 |
| `--accent-soft` | 強調色 14%／透明 | 輕量強調背景 |

`--ui-opacity` 控制介面背景透明度，不降低歌詞文字的不透明度。Full 與 Compact 各自保存透明度與歌詞字級，由介面將當前值寫入共用變數。

| 字體變數 | 主要字體 | 使用情境 |
| --- | --- | --- |
| `--display` | Anton，CJK 回退 Noto Sans JP | 標題、主要按鈕、海報式歌詞 |
| `--mono` | JetBrains Mono | 時間、快捷鍵、編號與狀態 |
| `--jp` | Noto Sans JP Variable | 日文及 CJK 內容 |
| `--tc` | Microsoft JhengHei UI，回退 Noto Sans JP | 繁體中文說明 |

Anton、JetBrains Mono、Noto Sans JP 隨 App 打包。新增視窗不得依賴線上字體；混合中英日文時保留既有 CJK fallback。

## 3. 模式與方塊

版面由 [styles.css](../app/src/styles.css) 定義；[deck.ts](../app/src/deck.ts) 管理方塊互動與元件所在面；[main.ts](../app/src/main.ts) 套用模式及視窗尺寸。

| 元素 | Full | Compact：收起歌詞 | Compact：展開歌詞 |
| --- | --- | --- | --- |
| 主背景、頁首與底部播放列 | 顯示 | 隱藏 | 隱藏 |
| 封面 | 方塊正面 | 正面 | 正面左側 |
| 歌詞 | 方塊外的閱讀區 | 隱藏 | 正面右側延伸區 |
| 音量環 | 右面 | 左面 | 左面 |
| 唱片 | 頂面 | 隱藏，頂面改放控制鈕 | 右面，保留 Seek |
| 歌名／歌手 | 主版面資訊 | 右側書背 | 頂面延伸區；書背隱藏 |
| Follow／Pin／Mini | 左面工具鈕 | 由頂面控制及指令提供相關操作 | 同左 |
| Source／Find／Reload | 背面 | 背面，另加 Settings | 同左 |
| 歌詞換行碎片 | 有條件觸發 | 不生成，立即清除現有碎片 | 有條件觸發 |

Compact 尺寸由歌詞字級、是否展開與 Wave 開關決定，不能手動縮放。切歌或切換翻譯不得改變視窗大小。拖動方塊旋轉；Compact 方塊旁的空白處可拖動視窗。

## 4. 控制元件與操作

- **工具鈕**：Full 的 Follow／Pin／Mini 與 Source／Find／Reload 共用 `.tool`、`.tool__glyph`。依方塊邊長 `--s` 縮放：高 `0.17s`、字級 `0.07s`、圖示邊長 `0.09s`，外框 1.5px。不得為其中一組另設較小圖示或文字。
- **圖示鈕**：沿用現有 SVG 筆畫與 `currentColor`；只有圖示的按鈕須有可讀名稱。持續狀態用 `aria-pressed` 表達；「回到 Full」是動作，不顯示為已按下的開關。
- **互動狀態**：Hover 使用強調色；選取／開啟沿用強調色底配黑字；不可用控制呈現 disabled。鍵盤焦點使用 2px 強調色輪廓、3px 外距。
- **點擊區**：按鈕的整個可見框均應能點擊，不能只讓文字或圖示可點。陰影、透視裝飾、碎片及其他覆蓋層使用 `pointer-events: none`，避免遮住控制。
- **封面**：點一下播放／暫停；Hover 圓形放大鏡內顯示「下一次點擊會執行」的播放或暫停圖示。拖動旋轉不觸發播放切換；左右切歌鈕各自處理操作。
- **唱片**：拖動時預覽時間與歌詞，放開後才送出一次 Seek；取消拖動不提交。單擊可播放／暫停，唱片中央的 Queue 按鈕不作為拖動起點。
- **播放狀態**：顏色、圖示與進度跟隨播放器確認的狀態；錯誤時恢復可確認的狀態，不留下誤導性的成功顯示。

## 5. 歌詞閱讀

- 沿用 `--lyric-size`；Full 與 Compact 的設定值分開保存。當前行、已唱過行及未唱行有清楚層次；字詞時間存在時才逐字高亮。
- Full 使用外部閱讀區；Compact 的延伸面以三行歌詞為目標，不能讓相鄰行殘片侵入閱讀區。
- Compact 有可見翻譯時，原文使用設定字級的 80%、行高 1.15；譯文為縮小後原文的 75%。進度底線位於譯文下方，不能穿過譯文。
- 翻譯不存在或關閉時，恢復無翻譯的字級與間距。只使用來源提供且能對齊的翻譯，不自行補內容。
- 歌名、歌手在窄面使用截斷；歌詞允許換行。超長原文／譯文可能超出三行構圖，修改排版時必須實測，不能只檢查短句。
- Follow 控制自動置中；手動 Seek、切歌及非連續跳轉不噴發換行碎片。

## 6. 動態效果

方塊與碎片效果見 [deck.ts](../app/src/deck.ts)；Wave 繪製與音訊生命週期見 [wave.ts](../app/src/wave.ts)，共用幾何參數見 [floor.ts](../app/src/floor.ts)。

- 方塊旋轉、懸浮、封面互動與背景漂移應服務操作回饋，避免讓使用者等待動畫才能執行下一步。
- 歌詞碎片只在可見歌詞正常向下一行自動跟隨時生成，每次 12 片、飛行約 1100ms。Compact 收起歌詞時同步隱藏碎片層、清除在途碎片，後續換行也不能生成。
- 歌詞隱藏時仍可更新播放位置；通知層獨立運作，不為了隱藏碎片而關閉整個通知區。
- Wave 在兩種模式各有開關；Strength 範圍 10–200%，預設 100%。預覽即時生效、取消恢復原值；調強不增加視窗大小或最高波塊高度。
- 系統設定 `prefers-reduced-motion` 時停用歌詞碎片、靜止背景漂移，Wave 不擷取音訊。新增動態效果也須考慮此設定。

## 7. 附屬視窗與文案

Settings、Source、Find lyrics、更新通知沿用 [panel.css](../app/src/panel.css) 的獨立無邊框視窗，以及 [sheet.css](../app/src/sheet.css) 的表單樣式。

- 共用面板：背景 `#0c0c0c`、36px 頁首、細外框；內容可捲動，底部操作區保持可用。
- 章節標題以小型等寬字、大寫、虛線分隔及強調色標記呈現；主要標題用展示字體。
- 一般欄位高 36px；`.ghost-button` 高 34px、1.5px 外框、13px 展示字體。超連結若執行主要動作，沿用同一按鈕外觀。
- Range 使用既有滑桿、數值及標籤排列；開關沿用既有 checkbox。設定須明確區分預覽、儲存與取消。
- Queue 保留傾斜面板；Refresh 與其他工具共用 `.hb`，圖示與文字置中，整個邊框可點。不要恢復「Spotify — Up next 20」或「點一下跳到這首」等重複說明。播放來源限制等會影響操作的訊息仍應保留。見 [queue.css](../app/src/queue.css)。
- Command Palette 是獨立視窗；命令支援中英文搜尋與快捷鍵設定。新增可重複使用的操作應檢查是否需要加入命令及快捷鍵清單。見 [palette.ts](../app/src/palette.ts)、[shortcuts.ts](../app/src/shortcuts.ts)。
- 更新通知只有找到較新正式版才顯示，提供 GitHub Release 與稍後關閉；自動檢查可在 Settings 關閉。提示不自行下載或安裝，網路失敗不阻塞主介面。
- 文案使用簡短、具體的動作名稱；介面以英文為主，保留既有中文輔助說明。不把內部程式流程放進使用者操作說明。

## 8. 修改與驗收

新增元件先檢查共用 token、`.tool`、`.ghost-button`、`.hb` 與 panel/sheet，避免複製出不同尺寸的同類控制。共同樣式改在共用檔，僅模式差異留在模式選擇器；不要用影響其他區域的父層隱藏來修局部問題。

依修改範圍驗證以下項目，並記錄未測項目：

- Full、Compact 收起與展開歌詞均可操作；模式切換、快速連按及重新開啟不留下舊元素。
- Compact 字級 12／18／26／44、有／無翻譯、長中英日文句子，沒有新的遮擋；歌詞內容切換不改變視窗尺寸。
- 自訂強調色、背景透明度與置頂狀態不破壞文字可讀性或焦點提示。
- Hover、按下、選取、disabled、鍵盤焦點與 Esc 行為符合既有控制；視覺框的邊緣也能點擊。
- 封面點擊與拖動分開；唱片預覽不提前提交 Seek，取消不提交。
- 歌詞隱藏後沒有碎片；恢復顯示後效果正常；減少動態效果設定受到尊重。
- 相關自動測試及正式版建置通過；涉及透視、遮罩或點擊區的改動另外用實際瀏覽器／App 驗證。
