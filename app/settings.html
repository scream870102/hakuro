Player

Hakuro follows one player at a time. Choose the YouTube Music desktop app you use; ytmdesktop and ytmdesktop2 connect separately.

Copy the Client ID from your Spotify Developer app. Set its redirect URI to http://127.0.0.1:8787/callback. No Client Secret is needed.

In ytmdesktop, turn on Settings → Integrations → Companion server and Enable companion authorization. Save these settings to connect, then approve Hakuro in ytmdesktop's authorization dialog within 30 seconds. Check that the code matches the one Hakuro shows.

You can control playback, volume and repeat, shuffle the queue, and choose a queued song here.

In ytmdesktop2, turn on Settings → API & Integrations → API and enter the port it shows. If it requires authorization, Hakuro shows a code when it connects: approve Hakuro under Authentication within 30 seconds.

Lyrics search order

Move sources up or down and select which ones to search. A song's preferred source takes priority.

    Converts lyrics and translations once, as they are downloaded, and saves the converted text. Japanese lyrics are never converted. Lyrics already saved stay as they are; use Reload lyrics to download a song again.

    Colors

    Window

    Thins the background so the desktop shows through. The lyrics stay fully opaque. Compact mode has no background at all: its window is the cube and nothing else.

    In compact mode this also sizes the cube, so its face always has room for three lines: the line being sung, and the one on either side.

    Only acts while the window is pinned on top. The Click-through shortcut below switches between off and always. Keep a global binding to regain mouse control.

    Sound wave / 波動

    A floor of tiles under the cube ripples with whatever this computer is playing. Music playing on another device, such as a phone controlled through Spotify Connect, makes no sound here, so the floor stays still. In compact mode the window grows to hold the floor. Strength sets how high the tiles rise for the same sound; above 100% quiet music moves them more, and loud music reaches the full height sooner.

    Cube gestures / 骰子手勢

    快速來回轉動方塊後放開，執行選定的 Command Palette 動作並回到預設角度。預設為 Random queue track，從接下來的 Queue 隨機選歌；選擇「不綁定」即可停用動作。動作是否可用，與 Command Palette 相同。

    Keyboard shortcuts / 快捷鍵

    Click a binding, then press your shortcut. Use Ctrl, Alt or Win with a key, or F1–F24. Esc cancels recording. Global works from other apps; otherwise the shortcut works in Hakuro's main window. Changes apply when saved.

    Updates / 更新

    When a newer version is available, show a notification with a link to the latest GitHub Release.
